# Networking

## Commands Practiced
  "ip addr" → show network interfaces & IP addresses
  "ip route" → display routing table
  "ping" → test connectivity to a host
  "curl" → fetch data from a URL
  "wget" → download files from the web
  "ss" → inspect sockets and listening ports
  "nslookup" → simple DNS query
  "dig" → advanced DNS lookup

## Concepts Understood
  **IP Address** → unique identifier for a device (IPv4/IPv6)
  **Port** → identifies a service on a host (e.g., 80 = HTTP, 443 = HTTPS)
  **DNS** → translates domain names into IP addresses
  **TCP** → reliable, connection-oriented protocol ensuring ordered delivery
  **HTTP/HTTPS** → web communication protocols (HTTP = plain, HTTPS = encrypted)
